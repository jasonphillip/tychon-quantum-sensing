# tychon-odmr-ml

Repo 2 of Tychon AI Phase I SBIR. Consumes ODMR synthetic datasets from Repo 1 (`tychon-nv-sim`) to train, quantize, and evaluate neural networks.

## Layout

- `src/tychon_odmr_ml/` — package source (src layout)
- `tests/unit/` — self-contained unit tests
- `tests/contract/` — contract tests against golden dataset
- `tests/smoke/` — end-to-end CPU-only smoke tests
- `docs/phase1-context/` — authoritative specs

## Golden Dataset

Located at `~/projects/tychon-shared-data/golden/` (dataset.h5 + manifest.json).
Generated by Repo 1 with master_seed=12345: 100 train / 20 val / 20 test, 100-point spectra.

## Commands

```bash
pip install -e ".[dev]"       # install in dev mode
make test                     # all tests
make test-unit                # unit tests only
make test-contract            # contract tests (need golden dataset)
make test-smoke               # smoke tests (need golden dataset)
```

## Dependencies

Runtime: torch, numpy, h5py, pyyaml
Dev: pytest

No CI, no pre-commit, no Claude skills on Day 1.

## Compute

This machine has a Blackwell GPU. Use device='cuda' for all training runs. CPU-only is acceptable for tiny models (<1000 params) but anything larger should use GPU. The DGX Spark's GPU is massively underutilized — training a 3K-param FCNN on CPU took 7 minutes; on GPU it would take seconds.

## Cross-Repo Data Flow
Repo 3 (tychon-polarfire-control) is scaffolded and on GitHub. .vnnx models from this repo's export pipeline go to ~/projects/tychon-shared-data/models/ and must be compiled with vnnx_compile -c V250 using SDK v2.0.3 in WSL on Beelink.
