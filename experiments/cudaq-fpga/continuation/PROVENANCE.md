# Public-copy provenance

This is a curated copy of the continuation workspace, collected October 17, 2026.
`SOURCE_MAP.json` records original and public SHA-256 hashes for every copied file.
All included numerical arrays, binary packs, and prediction/replay CSV files retain their original bytes.

Private machine names, home paths, and historical invocation paths were normalized in text copies.
Affected hash references were recalculated to identify the corresponding public copies.
These transformed registrations and receipts are publication copies, not the original bytes recorded during execution.
Original SHA-256 values remain in `SOURCE_MAP.json`; publication SHA-256 values verify this directory.
Historical timestamps, outcomes, numerical values, failed gates, and scope qualifiers remain.
Portable command strings in copied receipts describe equivalent paths; they are not literal original shell invocations.
Source locations containing machine identifiers use normalized role names in the mapping.

The generated aggregate verifier checks saved data without exact RNG regeneration.
The original exact-regeneration verifier and the original Mac failure remain for methods inspection.
The successful original Linux acceptance remains a historical receipt, not a new public-copy execution claim.

## Explicit exclusions

- Environments, caches, internal plans, ownership instructions, research/corpus captures, and outreach/positioning drafts.
- Hardware launch wrappers, redundant command logs, programming images, vendor IP, and toolchains.
- Unlicensed copied processor upstream code (`author_code/`); pinned upstream URLs and hashes remain in metadata.
- Cached third-party HTML, papers, notebooks, and internal transport bundles.
- Large processor source signal ranges and labels. Row ranges, source URLs, file hashes, and consumed-set markers remain.
- Unused thermal acquisitions and copied upstream analysis code. The licensed trace used by the saved thermal verifier remains.

The processor `--pack-only` check uses included derived records and predictions.
The processor full training-range verifier requires excluded external source data and is outside the offline package contract.
No excluded file is silently replaced by synthetic data.
See `SOURCE_MAP.json` for the exact excluded-file inventory and reasons.
