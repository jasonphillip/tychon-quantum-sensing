## Build planning: 2026-03-04 to 2026-04-30

Before the orchestrator repository existed, I ran the build from a claude.ai project. It held the original technical plan, the research and the 90-day execution playbook, and the prompts for the coding-agent sessions in each repository were written there. Gemini Deep Think reviewed the designs as a second model, and Claude annotated that review inside the project.

The documents under `docs/` are exports from that project, each with its original creation date on the first line. Other people's names and business planning were removed for publication. They were added to this repository on 2026-10-09, so their commit dates aren't their writing dates.
